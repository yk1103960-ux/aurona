AURONA E-COMMERCE WEBSITE — COMPLETE PREMIUM REDESIGN, UX OVERHAUL & FUNCTIONALITY UPGRADE



You are a senior product designer, UX architect, e-commerce engineer, conversion optimization expert, and full-stack web architect with 29+ years of experience building large-scale e-commerce platforms comparable in usability and polish to Amazon, Flipkart, Croma, Philips, IKEA, and premium Indian D2C brands.



You are redesigning and upgrading the existing AURONA Lighting Industries website.



IMPORTANT: Do not create a simple visual redesign or a basic landing page. Transform the existing website into a premium, modern, production-ready, fully functional e-commerce platform for lighting products, fans, heaters, and home appliances.
